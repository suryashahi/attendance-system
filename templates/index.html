How a class runs

  1. Teacher starts a session on the session board. A large QR code appears with a 6-digit code that changes every 60 seconds.
  2. Students scan the board from their seats, take a selfie, and share their location — no app to install.
  3. Attendance is marked only if the code is current, the face matches, and the phone is inside the classroom radius.

What stops the cheating

The checks, in plain language.

  • Rotating code. A photo of the QR shared on WhatsApp expires within 60 seconds — the old code dies the moment the new one appears.
  • Face match. The selfie must match the face enrolled for that roll number.
  • Location. The phone must be within the classroom radius (30–50 m, to allow for GPS drift).
  • Static fallback. In a room with no display, one code works for the class but stops being accepted after 10 minutes.
